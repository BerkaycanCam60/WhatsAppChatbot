Projemin amacı: WhatsAppChatbot SaaS

Çoklu işletme desteğine sahip, yapay zekâ destekli WhatsApp müşteri iletişim ve satış asistanı platformu.

* Proje Hakkında

WhatsAppChatbot, işletmelerin WhatsApp üzerinden müşterileriyle otomatik iletişim kurmasını, ürün ve fiyat bilgisi vermesini, stok sorgularını yanıtlamasını ve müşteri taleplerini yönetmesini sağlayan yapay zekâ destekli bir chatbot altyapısıdır.

Projenin temel amacı, tek bir chatbot altyapısının birden fazla işletmeye entegre edilebildiği, her işletmenin kendi ürünlerini, fiyatlarını, stoklarını, WhatsApp hesabını ve chatbot ayarlarını bağımsız olarak yönetebildiği bir **SaaS (Software as a Service)** platformu geliştirmektir.

Platform, işletmelerden bağımsız bir marka altında hizmet verecek şekilde tasarlanmaktadır.

---

* Projenin Hedefleri

- Birden fazla işletmeye aynı chatbot altyapısını sunmak.
- Her işletmenin verilerini birbirinden izole tutmak.
- İşletmeye özel ürün, fiyat ve stok yönetimi sağlamak.
- WhatsApp üzerinden otomatik müşteri iletişimi gerçekleştirmek.
- Yapay zekâ ile müşteri mesajlarını analiz etmek ve uygun yanıtlar üretmek.
- Müşteri taleplerini gerektiğinde gerçek bir işletme yetkilisine yönlendirmek.
- Gelecekte işletmeler için yönetim paneli ve abonelik sistemi oluşturmak.
- Sistemin ölçeklenebilir ve yeni işletmeler kolayca eklenebilir bir mimariye sahip olmasını sağlamak.

* Kullanılan Teknolojiler

| Teknoloji | Kullanım Amacı |
      -              -
| Node.js | Backend çalışma ortamı |
| Express.js | REST API ve webhook altyapısı |
| MongoDB Atlas | Veritabanı ve bulut veri yönetimi |
| MongoDB Node.js Driver | Veritabanı işlemleri |

| Axios | HTTP istekleri |
| dotenv | Ortam değişkenlerinin yönetimi |
| Git & GitHub | Versiyon kontrolü |
